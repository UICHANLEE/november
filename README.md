# 미션 QR 스캐너

참가자가 이름을 입력해 입장하면 관리자가 조를 배정합니다. QR 코드는 조별로 한 번만 인정되며 다른 조는 각각 사용할 수 있습니다. 기존 QR 15개를 일반 미션 10개와 어려운 미션 5개로 사용합니다. 일반 QR의 보상은 쌈무, 상추, 깻잎, 양파, 마늘, 파절임, 소스, 버섯, 소시지, 참소스 각 하나로 중복 없이 정해져 있습니다. 어려운 QR은 조마다 하나만 스캔할 수 있으며 미션 성공 시 고기 1개가 보상입니다.

## 운영 순서

1. `/admin.html`에서 관리자 비밀번호로 로그인합니다.
2. 새 행사를 시작하고, 참가자가 이름을 입력해 입장하도록 안내합니다.
3. 관리자 명단에서 각 참가자에게 조 번호를 배정합니다. 참가자 화면은 자동으로 배정을 확인합니다.
4. 참가자는 카메라를 켜고 QR 코드를 스캔합니다. 미션 내용과 실제 재료와 다르게 생긴 그림자가 나타납니다. 본부에서 미션을 완료한 뒤 재료 확인 버튼을 누르면 동일한 외곽선 안에 그려진 실제 재료 그림과 이름이 공개됩니다. 버튼 자체가 미션 완료 여부를 확인하지는 않으므로 본부에서 직접 확인합니다. 이미 같은 조가 찾은 코드는 추가 인정되지 않으며, 기존 미션을 다시 볼 수 있습니다. 어려운 QR은 조당 하나만 인정하므로, 첫 어려운 QR을 찾으면 다른 어려운 QR은 사용할 수 없습니다.
5. 관리자는 조별 재료 현황에서 미션을 확인하고 실제로 지급한 재료를 기록하거나, 목록에서 직접 재료를 추가할 수 있습니다. 같은 조에 같은 재료를 중복 추가할 수 없으며, 고기 지급 기록도 조당 하나입니다. 기존 QR 스캔이나 재료 공개는 자동 지급으로 처리되지 않습니다. 관리자 페이지에서 QR 인쇄 화면을 열고, 현재 참가자·조별 QR·지급 현황과 활동 로그를 각각 JSON 파일로 저장할 수 있습니다. 활동 로그에는 입장·배정·발견·중복 스캔·재료 공개·지급 기록이 포함됩니다. 새 행사 시작 전에 기록을 내려받으세요. 새 행사를 시작하면 이전 참가 기록과 찾기 기록은 새 행사에 적용되지 않습니다.

## 실행과 설정

정적 웹 파일은 `dist/`, Vercel 서버 함수는 `api/mission.js`에 있습니다. 함수에는 다음 환경 변수가 필요합니다.

- `KV_REST_API_URL`, `KV_REST_API_TOKEN`: Upstash Redis REST 연결 정보
- `MISSION_ADMIN_PASSWORD`: 관리자가 사용할 충분히 긴 무작위 비밀번호

실제 카메라와 서버 함수를 함께 확인하려면 위 환경 변수가 설정된 Vercel 환경에서 실행해야 합니다. 브라우저 카메라는 HTTPS 또는 localhost에서만 사용할 수 있습니다. `node tests/mission-api.cjs`로 모의 저장소를 사용하는 서버 동작 검사를 실행할 수 있습니다.

QR 코드는 전용 문자열을 담습니다. 다른 카메라 앱도 QR의 원시 문자열을 읽거나 복사할 수 있지만, QR 인정과 조별 중복 처리는 서버를 통해 수행하며, 미션 완료 여부는 본부에서 확인합니다. 참가 식별 정보는 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기로 접속하면 다시 입장하고 관리자에게 재배정을 받아야 합니다. 새 행사의 참가는 새로 등록합니다.

QR 인식에는 jsQR 1.4.0을 사용하며 라이선스는 `dist/vendor/jsQR-LICENSE.txt`에 있습니다.

이미지에 있던 나머지 재료는 `data/future-rewards.json`에 개별 피규어 활동 후보로만 보관합니다. 피규어 자동 인식과 자동 지급 기능은 아직 구현되지 않았지만, 관리자가 해당 재료를 수동으로 기록할 수 있습니다. 기존 행사 기록은 유지됩니다. 이전에 이미 스캔한 QR은 그대로 사용된 상태로 남습니다.

재료 그림은 `node scripts/generate-reward-illustrations.cjs`로 생성합니다. 그림자와 공개 그림이 같은 외곽선을 사용하는지 `node tests/reward-art.cjs`로 확인할 수 있습니다.

재료 공개 화면은 동일한 그림자 모양으로 사진 질감을 가립니다. `dist/assets/food/ingredient-atlas.jpg`는 CC0 마늘 사진을 질감 참고로 제작한 AI 이미지이며, 깻잎 질감에는 Alex Abair의 Wikimedia Commons 사진(CC BY 4.0)을 합성합니다. 원본과 라이선스, 변경 사항은 사이트의 `image-credits.html`에 표시합니다.
