# 미션 QR 스캐너

카메라로 전용 QR 코드를 인식해 난이도와 본부 미션 안내를 보여주는 정적 웹 앱입니다. 난이도 1~3별로 5개, 총 15개의 고유 QR 코드가 포함되어 있습니다.

## 실행

```sh
cd dist
python3 -m http.server 8000
```

같은 기기에서 http://localhost:8000 을 열면 됩니다. 휴대폰에서 사용하려면 HTTPS로 호스팅해야 카메라 접근이 가능합니다. 카메라를 허용한 뒤 QR 코드를 비추세요. 운영자용 `cards.html`에서 15개 코드를 인쇄할 수 있습니다. QR에는 웹 주소가 아니라 앱 전용 식별값이 들어 있습니다.

QR 목록은 `dist/codes.json`, 인쇄용 SVG는 `dist/qr/`에 있습니다. 인식은 jsQR 1.4.0을 사용하며 라이선스는 `dist/vendor/jsQR-LICENSE.txt`에 포함되어 있습니다. 전용 QR 값은 보안 인증 수단이 아니며, 복사나 재인식을 막지는 않습니다.
