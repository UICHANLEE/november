# 미션 QR 스캐너

참가자가 이름을 입력해 입장하면 관리자가 조를 배정합니다. QR 코드를 스캔하면 조별로 한 번만 미션이 인정되며, 다른 조의 기록은 별도로 관리합니다. 15개의 기존 QR 코드는 그대로 사용합니다.

## 운영 순서

1. `/admin.html`에서 관리자 비밀번호로 로그인합니다.
2. 새 행사를 시작하고, 참가자가 이름을 입력해 입장하도록 안내합니다.
3. 관리자 명단에서 각 참가자에게 조 번호를 배정합니다. 참가자 화면은 자동으로 배정을 확인합니다.
4. 참가자는 카메라를 켜고 QR 코드를 스캔합니다. 이미 같은 조가 찾은 코드라면 중복 안내가 나옵니다.
5. 관리자는 관리자 페이지에서 QR 인쇄 화면을 열고, 현재 참가자·조별 QR 현황과 활동 로그를 각각 JSON 파일로 저장할 수 있습니다. 활동 로그는 기능 추가 이후의 입장·배정·발견·중복 스캔만 기록합니다. 새 행사 시작 전에 기록을 내려받으세요. 새 행사를 시작하면 이전 참가 기록과 찾기 기록은 새 행사에 적용되지 않습니다.

## 실행과 설정

정적 웹 파일은 `dist/`, Vercel 서버 함수는 `api/mission.js`에 있습니다. 함수에는 다음 환경 변수가 필요합니다.

- `KV_REST_API_URL`, `KV_REST_API_TOKEN`: Upstash Redis REST 연결 정보
- `MISSION_ADMIN_PASSWORD`: 관리자가 사용할 충분히 긴 무작위 비밀번호

실제 카메라와 서버 함수를 함께 확인하려면 위 환경 변수가 설정된 Vercel 환경에서 실행해야 합니다. 브라우저 카메라는 HTTPS 또는 localhost에서만 사용할 수 있습니다. `node tests/mission-api.cjs`로 모의 저장소를 사용하는 서버 동작 검사를 실행할 수 있습니다.

QR 코드는 전용 문자열을 담습니다. 다른 카메라 앱도 QR의 원시 문자열을 읽거나 복사할 수 있지만, 미션 판정과 조별 중복 처리는 서버를 통해 수행합니다. 참가 식별 정보는 현재 브라우저의 로컬 저장소에 저장됩니다. 브라우저 데이터를 삭제하거나 다른 기기로 접속하면 다시 입장하고 관리자에게 재배정을 받아야 합니다. 새 행사의 참가는 새로 등록합니다.

QR 인식에는 jsQR 1.4.0을 사용하며 라이선스는 `dist/vendor/jsQR-LICENSE.txt`에 있습니다.
